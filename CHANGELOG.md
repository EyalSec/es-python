# Changelog

Changes you can see when you use es-python: what it reports, how it installs
and how it runs your code. The format follows
[Keep a Changelog 1.1.0](https://keepachangelog.com/en/1.1.0/).

## What is recorded here

- **Added**: a new operation, library or source that is now watched; a new
  supported distribution, architecture or Python version; a new command or flag.
- **Changed**: an event that now reads, grades or groups differently; a change
  to what a machine sends.
- **Fixed**: a flow that was missed and is now reported; an event that fired
  when it should not have; an install or compatibility problem.
- **Removed**: a flag, a source or a platform that is no longer supported,
  announced one release ahead where we can.
- **Security**: a fix for a vulnerability in EyalSec itself, with credit to the
  reporter if they want it.

Each entry says what changed for you and links the issue that asked for it.
es-python tracks upstream Python releases; an entry names the Python versions
it applies to.

Dashboard and API changes are not listed here; the
[user guide](https://eyalsec.com/docs) always describes the current behaviour.

## How to take a release

Reinstall the machine from your dashboard: click **Install** on its row and run
the new command. The machine keeps its name, settings and events. See
[Reinstalling and updating](https://eyalsec.com/docs/running-es-python#update).
`eyalsec info` shows the build each installed version is on.
